# Pagoda

A full-stack web application starter kit in Go. See **[PAGODA.md](PAGODA.md)** for the full documentation.

## Data layer

| Concern | Tool |
|---|---|
| Application database | PostgreSQL (via [pgx](https://github.com/jackc/pgx)) |
| Query code generation | [sqlc](https://sqlc.dev) — see `sqlc.yaml` |
| Schema migrations | [golang-migrate](https://github.com/golang-migrate/migrate), embedded and applied on startup |
| Task queue database | SQLite — [backlite](https://github.com/mikestefanello/backlite) is SQLite-only, so the queue keeps its own database |

```
sqlc.yaml                        # sqlc configuration
pkg/postgres/
├── migrations/                  # golang-migrate files; also sqlc's schema source
├── queries/                     # hand-written SQL -- the source of the generated code
├── db/                          # GENERATED by sqlc (package pgdb) -- never edit by hand
└── migrate.go                   # embeds migrations and applies them on startup
```

## Getting started

```bash
make install     # install sqlc, golang-migrate, air and the Tailwind CLI
make db-up       # start PostgreSQL (creates the "pagoda" and "pagoda_test" databases)
make run         # run the application; migrations are applied on startup
make admin email=myemail@web.com   # create an admin account
```

## Changing the schema

```bash
make migrate-new name=add_posts   # create the migration files
# ...write the up/down SQL, then add queries under pkg/postgres/queries/
make sqlc-gen                     # regenerate the type-safe Go code
```

sqlc reads the migrations directory as its schema source, so the generated code always matches the
migrated schema. Files ending in `.down.sql` are ignored by sqlc.

## Tests

Tests run against a real PostgreSQL database. Each test process isolates itself in a randomly-named
schema, so packages can run in parallel safely.

```bash
make db-up
make test
```

## Gotchas inherited from dropping the ORM

Ent's schema hooks used to enforce these silently. They are now explicit — see
[Things an ORM would do for you](PAGODA.md#things-an-orm-would-do-for-you):

- **Email lowercasing** is done in SQL (`LOWER()`). Don't lowercase in Go as well.
- **Password hashing** — call `AuthClient.HashPassword` before persisting. Nothing hashes for you.
- **Reset token hashing** — handled inside `AuthClient.GeneratePasswordResetToken`.

The generic entity CRUD admin panel was generated by an Ent codegen extension and has been removed.
The Backlite task dashboard at `/admin/tasks` is unaffected.
